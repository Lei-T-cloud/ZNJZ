📐 工程阈值标准（对接土木组赛题：屋面防渗漏 / 墙体保温差 / 结构承载不足）

三级分级：NORMAL 正常 · WARN 预警 · ALARM 报警
环境（GB 50736-2012 / GB 50034-2013）
监测项预警 WARN报警 ALARM工程含义
温度≥30℃ 或 ≤16℃≥35℃ 或 ≤10℃墙体保温差/制冷供暖失效
湿度≥70% 或 ≤30%≥85%屋面防渗漏/结露风险
光照<300 lx（办公室标准）<80 lx 很暗照明不足 / 过亮眩光
结构安全（JGJ 8-2016 变形测量规范 / 演示级阈值）
监测项预警 WARN报警 ALARM工程含义
倾斜角≥1.0°≥2.0°结构承载不足/不均匀沉降
振动量≥0.12 g≥0.25 g异常振动/扰动
角速度≥45 °/s≥90 °/s姿态突变
综合协同规则： 环境正常 + 结构正常 → 正常监测； 环境预警/报警 → 围护体检与维修派单（防渗漏、保温补强）； 结构预警/报警 → 承载力评估与加固； 环境+结构同时异常 → 综合应急派单； 无人 → 灯光自动关闭节能；有人 → 按照度分级照明。
