环境监测规则：
湿度 ≥ 75%：湿度过高，触发防渗、保温、霉变风险预警
湿度 ≤ 35%：湿度过低，触发干燥开裂风险预警
温度 ≥ 30℃：温度过高，触发高温环境预警
温度 ≤ 5℃：温度过低，触发低温环境预警
其他情况：环境稳定，记录底座数据
结构监测规则：
倾斜角 ≥ 12°：倾斜超限，触发结构红色预警
振动量 ≥ 0.35：振动超限，触发异常振动预警
陀螺仪最大值 ≥ 80：姿态变化过快，触发姿态异常预警
其他情况：结构稳定，记录底座数据
协同决策规则：
环境正常 + 结构正常：正常记录，记录底座数据
环境异常 + 结构正常：环境维修派单，围护结构体检与维修自动派单
环境正常 + 结构异常：结构加固派单，结构承载力评估与加固应急响应
环境异常 + 结构异常：综合预警派单，综合预警与维修派单
陀螺仪说明：
陀螺仪检测的是角速度，不是静态倾斜角。
机器静止或只是斜放不动时，陀螺仪数值可能接近 0。
需要快速转动或晃动机器，陀螺仪数值才会明显变化。
静态倾斜主要看 倾斜角、横滚角、俯仰角。
